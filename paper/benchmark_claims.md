# Benchmark claims for the JOSS submission

This file tracks each quantitative statement used in `paper.md`.  The focused
snapshot is generated by `scripts/generate_release_evidence.py`; its environment,
commands, source-tree digest, key results, and artifact SHA-256 hashes are stored
in `docs/_static/release_evidence.json`.

## Claim 1: quick small-sample heavy-tail profile

**Paper-ready claim**

Across the eight scenarios in the committed quick profile,
`AutoRobustScatter` has median relative Frobenius error `0.5907` and win rate
`0.8750`.  `RegularizedCauchy` is the strongest single estimator across all
eight scenarios with median error `0.5950`.

**Source artifacts**

- `docs/_static/benchmarks/small_sample.csv`
- `docs/_static/benchmarks/small_sample_summary.csv`
- `docs/_static/release_evidence.json`

**Reproduction**

```bash
python scripts/generate_release_evidence.py --source-revision "$(git rev-parse HEAD)"
```

**Status**

Verified for the quick profile.  The selector timing includes candidate fits;
this is not a larger repeated publication benchmark.

## Claim 2: FastMCD versus classical MCD on eligible scenarios

**Paper-ready claim**

On the four quick-profile scenarios where classical MCD is mathematically
applicable, native `FastMCD` has median relative Frobenius error `0.6774`,
compared with `0.8233` for scikit-learn `MinCovDet`.

**Source artifacts**

- `docs/_static/benchmarks/small_sample_summary.csv`
- `docs/_static/release_evidence.json`

**Status**

Verified.  Both methods are marked not applicable in the `p > n` scenarios;
those rows are not silently dropped from the artifact.

## Claim 3: independent FastMCD statistical validation

**Paper-ready claim**

In the fixed contaminated-Gaussian reference comparison, FastMCD covariance
agrees with scikit-learn `MinCovDet` to relative Frobenius error `0.00535`, and
the robust-distance correlation is effectively `1.0`.  Under 10--30 percent
injected row contamination, FastMCD covariance error remains between `0.126`
and `0.135`, while empirical covariance error ranges from `9.90` to `23.34`.

**Source artifacts**

- `docs/_static/benchmarks/statistical_validation.json`
- `docs/_static/release_evidence.json`

**Source script**

- `benchmarks/statistical_validation.py`

**Status**

Verified.

## Claim 4: robust SHAP explanation reference

**Paper-ready claim**

In the contaminated binary-Iris example, the robust support retains none of
the twelve injected leverage rows.  Total absolute SHAP attribution drift from
the clean reference is `2.528` for the contaminated empirical reference and
`0.388` for the robust reference.

**Source artifacts**

- `docs/_static/examples/robust_explanations_iris.json`
- `docs/_static/examples/robust_explanations_iris_output.txt`
- `docs/_static/examples/robust_explanations_iris.png`
- `docs/_static/release_evidence.json`

**Source script**

- `examples/robust_explanations_iris.py`

**Status**

Verified for the fixed model, query, seed, contamination pattern, and SHAP
settings.  It is an explanation-stability demonstration, not a universal model-
interpretability claim.

## Claim 6: hard-contamination honesty statement

The separate hard-contamination benchmark reports both favorable and
unfavorable scenarios.  In its mean-shift case scikit-learn `MinCovDet` has
lower relative Frobenius error than native `FastMCD`, whereas FastMCD is better
in the heavy-tail-inlier case.

**Source artifacts**

- `docs/_static/benchmarks/hard_scenarios.csv`
- `docs/benchmarks/hard_contamination.rst`

**Status**

Retained as an explicit limitation statement; this artifact was not regenerated
because the underlying hard-scenario implementation did not change.
